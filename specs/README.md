# Specifications

The project was built specification-first: each phase was scoped in a spec with
acceptance criteria, then implemented. These files are the **design history**.
Each one starts with a status note recording what was built and any differences
from the plan. For the current architecture, read
[`docs/architecture.md`](../docs/architecture.md).

Examples in the specs use the fictional *Larkspur Instruments* demo archive
(`email-archive demo`) or generic placeholders such as `archive-2003.pst`.
Measured figures (index times, thread sizes) come from real archives used during
development and are quoted without identifying details.

Start with [00 · System overview and roadmap](./00-system-overview-and-roadmap.md).
